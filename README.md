# 宜蘭 Yilan Drive

A small browser game: a golden-hour country road through the rice paddies of the Lanyang Plain in Yilan, Taiwan.
Walk around, get into the grey Porsche 911, and drive.

Play: https://zeredbaron.github.io/yilan-drive/

| Key | Action |
|---|---|
| WASD | walk or drive |
| Shift | run |
| E | get in or out of the car |
| Space | handbrake |
| H | horn |
| R | put the car back on the road |
| Mouse drag / wheel | orbit / zoom the camera |

Needs a desktop browser with a keyboard. Built with three.js; everything is in `index.html`.
